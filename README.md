# Python Power-Up (Cozmek)

Gamified Python lists & arrays learning game: 5 levels, Quick Learn + 6 questions each.

Files: `index.html`, `style.css`, `script.js`, `logo.png`.

## Deploy on GitHub Pages
Upload the 4 files to a repo, then Settings → Pages → deploy from `main` / root.

## Teacher dashboard
Click "Teacher dashboard" on the welcome screen. Change `ADMIN_PASSCODE` at the top of `script.js`.
Results are saved in the browser (localStorage) on the same device. For shared, secure storage across students, connect a backend such as Firebase or Supabase.
